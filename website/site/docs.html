Get started

From download to five agents and a paired phone. The README on GitHub has every detail.

Install

Download the zip, unzip it to a folder of your own and start AgentArcade.exe. If SmartScreen warns you, click More info → Run anyway.

Your first agents

  1. Add a project folder in the sidebar. Agents always start in the selected workspace.
  2. Click Install next to any agent you don't have. It shows the vendor's install command, then runs it in a pane. Codex, Gemini CLI and GitHub Copilot CLI need Node.js.
  3. Start an agent. The first time, it signs in through its own official login, in its own pane.

To add another command-line agent, add it to agents.json in %LOCALAPPDATA%\AgentArcade.

Panes and status dots

  • Orange while the agent works, red when it needs you, green when it's idle, grey when it has ended.
  • Windows notifies you when an agent is done or asks for your OK, unless you're already looking at its pane. Click the notification to jump to it. Turn notifications off in a pane's ⋯ menu.
  • Drag a pane by its header onto another pane to swap them. Double-click a title to rename the chat.
  • Drop files or images on a pane to paste their paths into the agent's prompt.
  • Text size: Ctrl = / Ctrl - / Ctrl 0 in a pane.

The side panel

The button at the right end of the top bar opens it. Preview shows a local address such as localhost:5173 or a page in the project. Images lists the project's images; drag one onto a pane. Changes shows what git sees changed, with diffs. Console is PowerShell in the project folder.

Extra accounts

A second Claude Code, Codex or Gemini CLI subscription gets its own folder, and the sidebar shows which email each account uses. You sign in to each one through the tool's own login. Agent Arcade never reads, copies or swaps login tokens, and never switches accounts by itself.

History and handoff

History lists every chat per project. Resume continues a chat: Claude Code reopens exactly that chat; the other agents open their own resume list. A pane's ⋯ menu pastes a "save progress" prompt (it writes HANDOFF.md) and a "continue" prompt, so the next agent can pick up where the last one stopped.

Pair your phone

  1. Sidebar → Phone → switch on Let my phone watch and drive these agents.
  2. If Windows asks, allow Agent Arcade on private networks. Your Wi-Fi must be set to Private (Settings → Network & internet → Wi-Fi → your network).
  3. On the phone: Scan QR code, check that the fingerprint matches the Phone dialog, and tap Pair.

The Android app is in early access; ask for it in Discussions.

Away from home

Install Tailscale on the PC and the phone and sign in with the same account. The pairing link lists the PC's Tailscale address after its Wi-Fi address, so the phone finds it either way. Tailscale's Personal plan is free for non-commercial use.

Keep-awake

By default Windows doesn't go to sleep on its own while agents run (the screen still turns off). In the Phone dialog, Keep this PC awake can also cover the time Phone remote is on. Windows still sleeps when you close the lid, press Sleep, or after a while on battery, so keep a laptop plugged in.

Troubleshooting

  • The phone can't connect. Check that your Wi-Fi is set to Private in Windows, that Phone remote is on, and that both devices are on the same network or on Tailscale.
  • An agent doesn't start. Make sure the project folder still exists and the agent is installed (its version shows in the sidebar).
  • Something else. Run AgentArcade.exe --self-check and read %TEMP%\AgentArcade-selfcheck.txt, then open an issue. Don't paste tokens or private terminal text.
