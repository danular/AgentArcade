Get started

From download to five agents and a paired phone. The README on GitHub has every detail.

Install

Download the zip and extract it to a folder of your choice, for example %LOCALAPPDATA%\Programs\AgentArcade. AgentArcade.exe is at the top of the zip; start it. If SmartScreen warns you, click More info → Run anyway. The download page shows how to check the file, what Smart App Control does, and how to uninstall.

Update

  1. Close Agent Arcade. Its agents stop; Recent in the sidebar can resume their chats afterwards.
  2. Extract the new zip over the old folder (the one that holds AgentArcade.exe) and replace the files.
  3. Start AgentArcade.exe. Settings, history and paired phones stay where they are, in %LOCALAPPDATA%\AgentArcade.

Your first agents

  1. Add a project folder with the + next to Projects in the sidebar, or make an empty one with New project. Agents always start in the selected project.
  2. Open Settings (the gear at the bottom of the sidebar) → Agents and accounts and click Install for any agent you don't have. It shows the vendor's install command, then runs it in a pane. Gemini CLI installs with npm and needs Node.js 20 or newer; GitHub Copilot CLI installs with WinGet; the others use their vendor's PowerShell installer. If something is missing, Install says what and links to it instead of running.
  3. Start an agent: New agent in the sidebar or the top bar (Ctrl N), or one click on a project's card on Home. The first time, it signs in through its own official login, in its own pane.

Gemini CLI needs a Gemini API key or a Gemini Code Assist Standard or Enterprise licence. Google stopped serving Gemini CLI for personal Google sign-ins (free, Google AI Pro and Ultra) on 18 Jun 2026. With a personal Google account, use Antigravity CLI, Google's replacement: it is in the agent list, and it signs in with Google when it starts.

To add another command-line agent, add it to agents.json in %LOCALAPPDATA%\AgentArcade.

Home, the sidebar and Settings

  • Home is the start screen: a card per project with its git branch and changed files, the agents running there with their status, a 10-day activity line, its last chats and one-click starts. Whatever needs you is listed on top; Open shows that pane.
  • The sidebar has New agent, Home, your projects with a status dot per running agent, and Recent: your chats across projects, newest first. Its footer says what needs you and what works, with the phone button and the gear for Settings (Ctrl ,).
  • A project's top bar shows its git branch and changed files (click it for the Changes tab), New agent and a ⋯ menu: Open folder, Images, Shared instructions, Open in Windows Terminal, Open in Unity for a Unity project, and the project's chat history.
  • Settings has General (text size, notifications, keep-awake, where new projects go, the update check, mascot animations), Agents and accounts, Phone, Shared instructions, MCP servers, and About with your version.
  • MCP servers lists each installed agent's MCP servers, from the agent's own list command in the selected project: only each server's name, scope and status, never its command line, keys or environment. Claude Code, Gemini CLI and Cursor check a server by connecting to it, so a check starts those servers briefly.

Panes and status dots

  • Orange while the agent works, red when it needs you, green when it's idle, grey when it has ended.
  • Windows notifies you when an agent is done or asks for your OK, unless you're already looking at its pane. Click the notification to jump to it. Turn notifications off in Settings → General or in a pane's ⋯ menu.
  • Drag a pane by its header onto another pane to swap them. Double-click a title to rename the chat.
  • Portrait or narrow window: turn a monitor on its side, or make the window taller than wide, and the panes stack instead of squeezing side by side; the side panel docks under them (drag its top edge). Below 900 px wide the sidebar becomes a drawer: the button left of the project name opens it. There's nothing to set; it follows the window.
  • Drop files or images on a pane to paste their paths into the agent's prompt.
  • Text size: Settings → General (S, M, L, XL or an exact size), or Ctrl = / Ctrl - / Ctrl 0 in a pane. It applies to every pane.

The side panel

The button at the right end of the top bar opens it. Preview shows a local address such as localhost:5173 or a page in the project. Images lists the project's images; drag one onto a pane. Changes shows what git sees changed, with diffs; the git chip next to the project name opens it too. Console is PowerShell in the project folder.

Extra accounts

A second Claude Code, Codex or Gemini CLI account gets its own folder (Settings → Agents and accounts → Add account…), and that tab shows which email each account uses. You sign in to each one through the tool's own login. Agent Arcade never reads, copies or swaps login tokens, and never switches accounts by itself.

Recent and handoff

Recent in the sidebar lists your chats across projects, newest first; click one to continue it, and the magnifier searches them. Chat history in a project's ⋯ menu lists every chat per project. Continuing a chat: Claude Code reopens exactly that chat; the other agents open their own resume list. A pane's ⋯ menu pastes a "save progress" prompt (it writes HANDOFF.md) and a "continue" prompt, so the next agent can pick up where the last one stopped.

Pair your phone

First install the Android app: download the APK on your phone. It isn't on Google Play yet.

  1. The phone button at the bottom of the sidebar (Settings → Phone) → switch on Let my phone watch and drive these agents.
  2. If Windows asks, allow Agent Arcade on private networks. On your own home Wi-Fi, set the network to Private (Settings → Network & internet → Wi-Fi → your network); on a Public network Windows blocks the phone. On shared Wi-Fi (an office, a café, a hotel) keep it Public and use Tailscale instead.
  3. Click Pair a phone in the Phone tab. The QR code appears only then, and it disappears when you leave the tab or close Settings.
  4. On the phone: Scan QR code, check that the fingerprint matches the Phone tab, and tap Pair.
  5. Back on the PC, the Phone tab asks whether to pair this phone. Click Allow. Nothing is paired until you do; Remote 1.0 phones give up after about 15 seconds, so answer quickly or update the app.

Away from home

Install Tailscale on the PC and the phone and sign in with the same account. The pairing link lists the PC's Tailscale address after its Wi-Fi address, so the phone finds it either way. Tailscale's Personal plan is free for non-commercial use. When Tailscale can't link the two devices directly, it relays the encrypted traffic through its own DERP servers.

Keep-awake

By default Windows doesn't go to sleep on its own while agents run (the screen still turns off). In Settings → General, Keep this PC awake can also cover the time Phone remote is on, or be switched off. Windows still sleeps when you close the lid, press Sleep, or after a while on battery, so keep a laptop plugged in.

Troubleshooting

  • The phone can't connect. Check that Phone remote is on and that both devices are on the same network or on Tailscale. On your own home Wi-Fi, check that it is set to Private in Windows; on shared Wi-Fi, use Tailscale.
  • An agent doesn't start. Make sure the project folder still exists and the agent is installed (its version shows in Settings → Agents and accounts).
  • Something else. Run AgentArcade.exe --self-check and read %TEMP%\AgentArcade-selfcheck.txt, then open an issue and paste only the lines that start with FAIL: the rest of the report lists your account emails and folder paths. A FAIL line can name a folder too, so read it before you paste. Don't paste tokens or private terminal text.
