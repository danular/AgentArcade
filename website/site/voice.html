How it works

Click into a pane, hold the keys, talk

  1. Click into any text box: a terminal running Claude Code, VS Code, a browser, anything.
  2. Hold Ctrl Shift Space and talk, or tap it to start and tap again to stop. A small mic button works too, without stealing focus. Esc cancels.
  3. The cleaned text is pasted where your cursor was. If no text box has focus, it goes on the clipboard instead.

Built for code

Fillers and stutters go; npm, .env, C# and .NET stay as you write them. Add your own "wrong => Right" fixes for names Whisper gets wrong.

Fast enough to keep talking

Long prompts are transcribed while you talk. On our test laptop (Intel Core Ultra 7 155H, GPU), a one-minute prompt was typically ready about 2–3 seconds after stopping. Times vary with hardware.

English and Dutch

Both work without switching anything. Whisper large-v3-turbo runs on a Vulkan-capable GPU, or a smaller model on the CPU.

Prompt Coach · planned

Fewer corrections, round after round

A prompt that needs correcting costs you another round. Planned for Voice: a local history of the prompts you dictate into AI agents, and Prompt Coach to show your week: prompts, speaking pace, fillers, and whether the agent got it right first time.

Analyse will give a score, tips and rewrites of your own prompts, and the habits to work on. Analysis will run only when you press the button, through your own Claude Code sign-in, and count toward your own Claude usage. You'll be able to turn history off or delete it at any time.

Privacy

Your voice stays on your PC

How Voice is built to handle your data when it ships.

AudioTranscribed on your PC and kept in memory. Never uploaded, never saved to disk.
Prompt history (planned)A local file on your PC, for Prompt Coach. You'll be able to turn it off or delete it any time.
Prompt Coach "Analyse" (planned)Prompt text will go to Anthropic through your own Claude Code sign-in, only when you press Analyse.
Speech modelDownloaded once, the first time you start Voice.
Licence check (planned)With Pro checkout, Voice will check your key at most once a day and keep dictating offline. The check will send only the key.

Requirements: Windows 11 x64. A Vulkan-capable GPU for the fast model, otherwise the CPU. Prompt Coach's Analyse (planned) will need Claude Code installed and signed in. Pasting into windows that run as administrator doesn't work.
