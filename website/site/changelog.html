Changelog

What's new

Every release is on GitHub Releases, with its download and SHA-256.

1.3.416 Oct 2026
  • Security: the Changes tab no longer runs programs that a repository's own git config names (fsmonitor, filters, textconv), and never reaches a network share. When a config includes other files or names another work tree, the tab shows those lines and waits for Run git here anyway; a changed config asks again.
  • Security: clicking an image path never opens a network path.
  • Privacy: chat titles come only from what you type: pasted text and lines that look like keys never become a title, and titles stop at 60 characters. Keys already in saved titles are hidden once, and the phone gets titles and summaries with keys hidden.
  • Alerts you can rely on: a question that shows right after you press Enter now alerts once, as it appears. Your PC counts as "seen" only while you're actually there: recent keyboard or mouse input and an unlocked session. Walk away or lock the PC, and the toast and phone alert come anyway.
  • Updates: the sidebar shows your version, and once a day the app asks GitHub whether a newer release exists (no identifier is sent; switch it off by clicking the version). A second copy started from another folder now says where Agent Arcade already runs.
  • The self-check report hides emails, your user folder and your network name, so it's safer to share. Pane ids start at a random number each run.
  • The Gemini CLI hint says it needs a Gemini API key or Code Assist; personal Google accounts should use Antigravity CLI.
  • Agent Arcade Remote 1.1 beta (Android): an answer is sent once per question, typing during a question first dismisses it so a reply never approves by accident, answers pause while the connection is down, alerts survive app switches, reboots and updates, lock-screen alerts hide the question, and the QR scanner is fetched on first use. It has a new app id, so uninstall 1.0 once and pair again.
1.3.315 Oct 2026
  • Security: agent sessions no longer run a program from the project folder by its bare name, so a node.bat or node.cmd planted in a cloned repository doesn't run in place of Node.js (NoDefaultCurrentDirectoryInExePath=1).
  • Privacy: the window (Microsoft WebView2) no longer sends page addresses to Microsoft SmartScreen, and its crash dumps stay on your PC instead of going to Microsoft.
  • The download ships the .NET 10.0.13 runtime, Microsoft's security release of 13 Oct 2026.
  • Flat zip: AgentArcade.exe sits at the top of the zip, so you update by extracting the new zip over the old folder. Every release now has exactly two files: AgentArcade-win-x64.zip and AgentArcadeRemote.apk.
  • The Android app stays at version 1.0.
1.3.215 Oct 2026
  • New project: the folder icon next to + makes an empty folder next to your current project and opens it, like New project on the phone.
  • Android app: download Agent Arcade Remote as an APK from the download page.
  • Phone remote: New project no longer lists a folder twice when the sidebar already had it.
1.3.115 Oct 2026
  • A new install starts in your Documents folder, so you can start an agent right away. Add your own project folders in the sidebar.
  • The starter AGENTS.md is general; only Unity projects get the Unity rules.
  • Phone remote: name a new project on the phone and the PC makes an empty folder next to your other projects.
  • Self-contained download: the .NET runtime is inside the zip.
1.3.015 Oct 2026
  • Phone remote: watch and drive your agents from the Android app over Wi-Fi or Tailscale, with no Agent Arcade server in between and a pinned HTTPS certificate.
  • Side panel: Preview, Images, Changes and Console next to your panes.
  • Keep-awake: Windows doesn't go to sleep on its own while agents run.
1.2.012 Oct 2026
  • Run Claude Code, Codex, Gemini CLI, GitHub Copilot CLI and Cursor side by side, each in its own pane, with status dots, notifications, workspaces, history and extra accounts.
  • Drop files and images on a pane to paste their paths.
  • App icon, agent logos and a foldable sidebar.
