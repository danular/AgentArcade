Install

  1. Download the zip. If Microsoft Edge says it isn't commonly downloaded, open the download's ⋯ menu, choose Keep, then Show more → Keep anyway.
  2. Extract it to a folder of your choice, for example %LOCALAPPDATA%\Programs\AgentArcade. AgentArcade.exe is at the top of the zip. Keep the files together: the app needs the web folder next to it. No administrator rights needed.
  3. Start AgentArcade.exe. Windows may warn you the first time; see SmartScreen below.
  4. Add a project folder in the sidebar and start an agent. A new install opens in your Documents folder until you add one.

Check the file

If Windows says it "protected your PC"

Agent Arcade isn't code-signed yet, so Windows SmartScreen doesn't know it. Click More info, then Run anyway. It stays unsigned until a code-signing certificate arrives; until then you can check the file yourself, and the full source is public on GitHub.

Smart App Control

If Smart App Control is on (Windows Security → App & browser control), Windows blocks unsigned apps it doesn't know, and it has no per-app exception. So while Agent Arcade is unsigned, it can't start on a PC with Smart App Control on. Microsoft explains Smart App Control and your options.

Update

  1. Close Agent Arcade. Its agents stop; History can resume their chats afterwards.
  2. Extract the new zip over the old folder (the one that holds AgentArcade.exe) and replace the files.
  3. Start AgentArcade.exe. Settings, history and paired phones stay where they are, in %LOCALAPPDATA%\AgentArcade.

Uninstall

1. The app and its data. Close Agent Arcade, then delete its folder (the one that holds AgentArcade.exe) and %LOCALAPPDATA%\AgentArcade, which holds your settings, agent list, history, paired phones, the log and the window's WebView2 data. If you installed it with install.ps1, also delete the Agent Arcade shortcut in the Start menu.

2. The phone remote's certificate. If you ever turned Phone remote on, Agent Arcade made a certificate in your Windows user certificate store. Delete it in certmgr.msc (Personal → Certificates → Agent Arcade Remote), or with its private key in PowerShell:

Get-ChildItem Cert:\CurrentUser\My | Where-Object Subject -eq 'CN=Agent Arcade Remote' | Remove-Item -DeleteKey

3. The firewall rule. When you allowed Agent Arcade at the Windows firewall prompt, Windows made inbound rules for AgentArcade.exe. Remove them in Windows Security → Firewall & network protection → Allow an app through firewall → Change settings → agentarcade.exe → Remove, or in PowerShell run as administrator:

Get-NetFirewallApplicationFilter | Where-Object Program -like '*\AgentArcade.exe' | Get-NetFirewallRule | Remove-NetFirewallRule

4. The phone. Uninstall Agent Arcade Remote on your phone.

Get your agents

Agent Arcade runs the official command-line agents. Click Install in the sidebar for any you don't have yet: it shows you the vendor's install command first, then runs it in a pane you can watch. Codex, GitHub Copilot CLI and Gemini CLI need Node.js; Cursor installs with its own PowerShell installer. Each agent then signs in through its own official login. Gemini CLI needs a Gemini API key or a Gemini Code Assist Standard or Enterprise licence: Google stopped serving it for personal Google sign-ins on 18 Jun 2026.

The Android app

Agent Arcade Remote lets you watch and drive your agents from your phone. It isn't on Google Play yet, so you install the APK yourself. The PC side is already in the zip above: Phone at the bottom of the sidebar. Read how it works.

Download AgentArcadeRemote.apk

v1.1.0-beta.1 · 3.8 MB · Android 8.0 and up · free

  1. Download it on your phone. Open this page in your phone's browser and tap the button.
  2. Open the downloaded file. If Android asks, allow your browser to install unknown apps, then go back.
  3. Tap Install. If Google Play Protect says it doesn't know the app, tap More details, then Install anyway.
  4. Pair it with your PC: see Pair your phone.

To update, download the newest APK and install it over the old one. Your pairing stays.

Coming from version 1.0? Version 1.1 is a new app to Android (its app id changed to prepare for Google Play), so it can't install over 1.0. Uninstall the old Agent Arcade Remote first, install 1.1, and pair again: remove the old phone in the PC's Phone dialog, then scan a new code.

Requirements

  • Windows 11 on x64. Windows 10 and Windows on ARM aren't tested yet.
  • WebView2, which Windows 11 includes.
  • The agents you want to run, and their subscriptions or API keys.
  • For the phone remote: on your own home Wi-Fi, the network set to Private in Windows; on shared Wi-Fi, keep it Public and use Tailscale.

Build from source

With the .NET 10 SDK installed:

git clone https://github.com/danular/AgentArcade.git
cd AgentArcade
powershell -ExecutionPolicy Bypass -File install.ps1

This publishes the app to %LOCALAPPDATA%\Programs\AgentArcade and adds a Start menu shortcut. AgentArcade.exe --self-check runs the built-in checks.
