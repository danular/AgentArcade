Install in three steps

  1. Unzip it to a folder of your own, for example %LOCALAPPDATA%\Programs\AgentArcade. Keep the files together: the app needs the web folder next to it. No administrator rights needed.
  2. Start AgentArcade.exe. Windows may warn you the first time; see SmartScreen below.
  3. Add a project folder in the sidebar and start an agent. A new install opens in your Documents folder until you add one.

If Windows says it "protected your PC"

The download isn't code-signed yet, so Windows SmartScreen doesn't know it. Click More info, then Run anyway. Code signing is planned; until then you can check the file yourself, and the full source is public on GitHub.

Check the file

The SHA-256 of AgentArcade-1.3.1-win-x64.zip (the same file as AgentArcade-win-x64.zip):

In PowerShell, in the folder you downloaded it to:

Get-FileHash .\AgentArcade-win-x64.zip

Get your agents

Agent Arcade runs the official command-line agents. Click Install in the sidebar for any you don't have yet: it shows you the vendor's install command first, then runs it in a pane you can watch. Codex, Gemini CLI and GitHub Copilot CLI need Node.js; Cursor installs with its own PowerShell installer. Each agent then signs in through its own official login.

The phone remote

Agent Arcade Remote for Android is in early access and not on Google Play yet. The PC side is already in this download: Phone at the bottom of the sidebar. Read how it works, or ask for early access in GitHub Discussions.

Requirements

  • Windows 11 on x64. Windows 10 and Windows on ARM aren't tested yet.
  • WebView2, which Windows 11 includes.
  • The agents you want to run, and their subscriptions.
  • For the phone remote: your Wi-Fi set to Private in Windows, or Tailscale.

Build from source

With the .NET 10 SDK installed:

git clone https://github.com/danular/AgentArcade.git
cd AgentArcade
powershell -ExecutionPolicy Bypass -File install.ps1

This publishes the app to %LOCALAPPDATA%\Programs\AgentArcade and adds a Start menu shortcut. AgentArcade.exe --self-check runs the built-in checks.
