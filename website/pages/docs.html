Get started

From download to five agents and a paired phone. The README on GitHub has every detail.

Install

Download the zip and extract it to a folder of your choice, for example %LOCALAPPDATA%\Programs\AgentArcade. AgentArcade.exe is at the top of the zip; start it. If SmartScreen warns you, click More info → Run anyway. The download page shows how to check the file, what Smart App Control does, and how to uninstall.

Update

  1. Close Agent Arcade. Its agents stop; History can resume their chats afterwards.
  2. Extract the new zip over the old folder (the one that holds AgentArcade.exe) and replace the files.
  3. Start AgentArcade.exe. Settings, history and paired phones stay where they are, in %LOCALAPPDATA%\AgentArcade.

Your first agents

  1. Add a project folder in the sidebar with +, or make an empty one next to your current project with New project. Agents always start in the selected workspace.
  2. Click Install next to any agent you don't have. It shows the vendor's install command, then runs it in a pane. Codex, GitHub Copilot CLI and Gemini CLI need Node.js.
  3. Start an agent. The first time, it signs in through its own official login, in its own pane.

Gemini CLI needs a Gemini API key or a Gemini Code Assist Standard or Enterprise licence. Google stopped serving Gemini CLI for personal Google sign-ins (free, Google AI Pro and Ultra) on 18 Jun 2026.

To add another command-line agent, add it to agents.json in %LOCALAPPDATA%\AgentArcade.

Panes and status dots

  • Orange while the agent works, red when it needs you, green when it's idle, grey when it has ended.
  • Windows notifies you when an agent is done or asks for your OK, unless you're already looking at its pane. Click the notification to jump to it. Turn notifications off in a pane's ⋯ menu.
  • Drag a pane by its header onto another pane to swap them. Double-click a title to rename the chat.
  • Drop files or images on a pane to paste their paths into the agent's prompt.
  • Text size: Ctrl = / Ctrl - / Ctrl 0 in a pane.

The side panel

The button at the right end of the top bar opens it. Preview shows a local address such as localhost:5173 or a page in the project. Images lists the project's images; drag one onto a pane. Changes shows what git sees changed, with diffs. Console is PowerShell in the project folder.

Extra accounts

A second Claude Code, Codex or Gemini CLI account gets its own folder, and the sidebar shows which email each account uses. You sign in to each one through the tool's own login. Agent Arcade never reads, copies or swaps login tokens, and never switches accounts by itself.

History and handoff

History lists every chat per project. Resume continues a chat: Claude Code reopens exactly that chat; the other agents open their own resume list. A pane's ⋯ menu pastes a "save progress" prompt (it writes HANDOFF.md) and a "continue" prompt, so the next agent can pick up where the last one stopped.

Pair your phone

First install the Android app: download the APK on your phone. It isn't on Google Play yet.

  1. Sidebar → Phone → switch on Let my phone watch and drive these agents.
  2. If Windows asks, allow Agent Arcade on private networks. On your own home Wi-Fi, set the network to Private (Settings → Network & internet → Wi-Fi → your network); on a Public network Windows blocks the phone. On shared Wi-Fi (an office, a café, a hotel) keep it Public and use Tailscale instead.
  3. Click Pair a phone in the Phone dialog. The QR code appears only then, and it disappears when you close the dialog.
  4. On the phone: Scan QR code, check that the fingerprint matches the Phone dialog, and tap Pair.
  5. Back on the PC, the Phone dialog asks whether to pair this phone. Click Allow. Nothing is paired until you do; Remote 1.0 phones give up after about 15 seconds, so answer quickly or update the app.

Away from home

Install Tailscale on the PC and the phone and sign in with the same account. The pairing link lists the PC's Tailscale address after its Wi-Fi address, so the phone finds it either way. Tailscale's Personal plan is free for non-commercial use. When Tailscale can't link the two devices directly, it relays the encrypted traffic through its own DERP servers.

Keep-awake

By default Windows doesn't go to sleep on its own while agents run (the screen still turns off). In the Phone dialog, Keep this PC awake can also cover the time Phone remote is on. Windows still sleeps when you close the lid, press Sleep, or after a while on battery, so keep a laptop plugged in.

Troubleshooting

  • The phone can't connect. Check that Phone remote is on and that both devices are on the same network or on Tailscale. On your own home Wi-Fi, check that it is set to Private in Windows; on shared Wi-Fi, use Tailscale.
  • An agent doesn't start. Make sure the project folder still exists and the agent is installed (its version shows in the sidebar).
  • Something else. Run AgentArcade.exe --self-check and read %TEMP%\AgentArcade-selfcheck.txt, then open an issue and paste only the lines that start with FAIL: the rest of the report lists your account emails and folder paths. A FAIL line can name a folder too, so read it before you paste. Don't paste tokens or private terminal text.
