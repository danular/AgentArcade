Changelog

What's new

Every release is on GitHub Releases, with its download and SHA-256.

1.5.416 Oct 2026
  • Much less GPU while agents work: the pulsing "working" dots and the mascot's antenna made the window redraw at your screen's refresh rate the whole time an agent worked, about 10–14% of a laptop GPU. They now pulse in three steps, which costs about 1%.
1.5.316 Oct 2026
  • This release only ships {{remote}} 1.1.2. Agent Arcade on the PC is the same as 1.5.2, so there's no need to update it just for this.
  • {{remote}} 1.1.2: the Connect screen's steps match Agent Arcade 1.5: open Settings → Phone (the phone button at the bottom of the sidebar), switch on Let my phone watch and drive these agents, click Pair a phone, scan the QR code, then click Allow on your PC.
1.5.216 Oct 2026
  • Moving the mouse over a Codex pane while you type no longer puts codes like <35;12;9M in the chat's title. Titles that already have them are cleaned once; a title made only of them goes back to Untitled chat.
  • The Phone tab no longer says Windows blocks your phone on a public network when Windows' own rule for Agent Arcade already allows public networks.
1.5.116 Oct 2026
  • A project's welcome screen no longer cuts off the logo at the top when its agent cards don't fit the window; it scrolls from the top instead.
1.5.016 Oct 2026
  • A calmer window: the sidebar holds New agent (Ctrl+N), Home, your projects with a status dot per running agent, and your recent chats; its footer says what needs you, next to the phone button and the gear. A project's top bar keeps only its git branch and changed files (click it for the Changes tab), New agent, a ⋯ menu (Open folder, Images, Shared instructions, Windows Terminal, Unity, the project's chat history) and the side panel.
  • Home: every project as a card, with its branch, the agents running there and their status, a 10-day activity line, its last chats and one-click starts. Whatever needs you is listed on top, and Pick up where you left off has your newest chats.
  • Recent in the sidebar: your chats across projects, newest first, in Today, Yesterday and Earlier. Click one to continue it; the magnifier searches them.
  • One Settings window (the gear, or Ctrl+,): General (text size, notifications, keep-awake, the update check, and where new projects go, now a folder you can pick), Agents and accounts, Phone, Shared instructions, MCP servers and About. The Phone dialog is now its Phone tab, with the same Allow or Deny for every new phone.
  • MCP servers: each agent's MCP servers and whether they answer, from the agent's own list command in your project. Only names, scope and status are shown, never a server's command line, keys or environment.
  • A mascot: the robot from the app icon lives in the sidebar now. It blinks, follows your pointer and wears your agents' status on its antenna, and it likes being clicked. Mascot animations in Settings, or Windows' reduce-motion setting, keeps it still.
1.4.116 Oct 2026
  • Antigravity CLI is a built-in agent, for personal Google accounts now that Gemini CLI needs an API key or Code Assist. Its approval prompts light the red dot.
  • Install works on a clean PC: Codex and GitHub Copilot CLI install with their makers' official Windows installers, Agent Arcade finds Claude Code in its own install folder even when it isn't on PATH, and Install checks for Node.js, npm or WinGet first and tells you what's missing instead of failing in a pane.
  • Shift+Enter adds a new line to your prompt instead of sending it.
  • Each status has its own shape as well as its colour (needs-you is a diamond), with its name for screen readers.
  • The side panel leaves every column of panes room to work, and floats over them when the window is narrow. Agent Arcade remembers its window size, place and maximized state.
  • On a new install, New project makes folders in %USERPROFILE%\source\repos.
  • Claude Code's task lists count right (■ is in progress). Status detection for Claude Code, Codex, Copilot, Cursor and Antigravity is pinned by golden-screen tests that run on every build.
  • The website is easier to read and use on phones and with a keyboard, and the README and home page compare Agent Arcade with Happy, Paseo, Coucou, Warp and Claude Remote Control, with sources.
  • {{remote}} 1.1.1: pairing links accept only local and Tailscale addresses and strip hidden characters from the PC name; pairing with a new PC first unpairs the old one ("This replaces …"); Forget says when the PC couldn't be reached; the PC's Tailscale address is kept even when a state leaves it out.
1.4.016 Oct 2026
  • You approve every phone: opening the Phone dialog no longer makes a pairing code. Click Pair a phone to show the QR code; closing the dialog clears it. When a phone uses the code, the Phone dialog asks you to Allow or Deny it, with the phone's name and app version. Nothing is paired until you allow it. Copy link keeps the link out of Windows clipboard history.
  • A tap answers only the question you saw: {{remote}} 1.1 sends the question and screen it showed with every answer. If the question on your PC changed in the meantime, the PC refuses and types nothing. The PC also never presses Enter while a question is open, for any phone version.
  • No crossed wires after a restart: each start of Agent Arcade gets its own id, so a phone can't send to a different agent that happens to reuse an old pane number, and old alerts and chats close.
  • The Phone dialog shows each phone's app version, and every phone error now has a code the app can act on (the phone remote contract is now 1.1; 1.0 phones keep working).
  • Agents show neutral monograms (CC, CX, GM, CP, CU) instead of vendor logos, in the app and on the website. The download and phone pages have an Add to Obtainium link, so Obtainium can keep the Android app up to date.
  • {{remote}} 1.1: pairing waits for Allow on your PC; a changed question shows "The question changed" instead of answering; chats from before a PC restart say the agent is gone; the app asks you to update itself or Agent Arcade when versions don't fit; the chat keeps the last lines in view; Rename starts with the title selected.
1.3.416 Oct 2026
  • Security: the Changes tab no longer runs programs that a repository's own git config names (fsmonitor, filters, textconv), and never reaches a network share. When a config includes other files or names another work tree, the tab shows those lines and waits for Run git here anyway; a changed config asks again.
  • Security: clicking an image path never opens a network path.
  • Privacy: chat titles come only from what you type: pasted text and lines that look like keys never become a title, and titles stop at 60 characters. Keys already in saved titles are hidden once, and the phone gets titles and summaries with keys hidden.
  • Alerts you can rely on: a question that shows right after you press Enter now alerts once, as it appears. Your PC counts as "seen" only while you're actually there: recent keyboard or mouse input and an unlocked session. Walk away or lock the PC, and the toast and phone alert come anyway.
  • Updates: the sidebar shows your version, and once a day the app asks GitHub whether a newer release exists (no identifier is sent; switch it off by clicking the version). A second copy started from another folder now says where Agent Arcade already runs.
  • The self-check report hides emails, your user folder and your network name, so it's safer to share. Pane ids start at a random number each run.
  • The Gemini CLI hint says it needs a Gemini API key or Code Assist; personal Google accounts should use Antigravity CLI.
  • {{remote}} 1.1 beta (Android): an answer is sent once per question, typing during a question first dismisses it so a reply never approves by accident, answers pause while the connection is down, alerts survive app switches, reboots and updates, lock-screen alerts hide the question, and the QR scanner is fetched on first use. It has a new app id, so uninstall 1.0 once and pair again.
1.3.315 Oct 2026
  • Security: agent sessions no longer run a program from the project folder by its bare name, so a node.bat or node.cmd planted in a cloned repository doesn't run in place of Node.js (NoDefaultCurrentDirectoryInExePath=1).
  • Privacy: the window (Microsoft WebView2) no longer sends page addresses to Microsoft SmartScreen, and its crash dumps stay on your PC instead of going to Microsoft.
  • The download ships the .NET 10.0.13 runtime, Microsoft's security release of 13 Oct 2026.
  • Flat zip: AgentArcade.exe sits at the top of the zip, so you update by extracting the new zip over the old folder. Every release now has exactly two files: AgentArcade-win-x64.zip and AgentArcadeRemote.apk.
  • The Android app stays at version 1.0.
1.3.215 Oct 2026
  • New project: the folder icon next to + makes an empty folder next to your current project and opens it, like New project on the phone.
  • Android app: download {{remote}} as an APK from the download page.
  • Phone remote: New project no longer lists a folder twice when the sidebar already had it.
1.3.115 Oct 2026
  • A new install starts in your Documents folder, so you can start an agent right away. Add your own project folders in the sidebar.
  • The starter AGENTS.md is general; only Unity projects get the Unity rules.
  • Phone remote: name a new project on the phone and the PC makes an empty folder next to your other projects.
  • Self-contained download: the .NET runtime is inside the zip.
1.3.015 Oct 2026
  • Phone remote: watch and drive your agents from the Android app over Wi-Fi or Tailscale, with no Agent Arcade server in between and a pinned HTTPS certificate.
  • Side panel: Preview, Images, Changes and Console next to your panes.
  • Keep-awake: Windows doesn't go to sleep on its own while agents run.
1.2.012 Oct 2026
  • Run Claude Code, Codex, Gemini CLI, GitHub Copilot CLI and Cursor side by side, each in its own pane, with status dots, notifications, workspaces, history and extra accounts.
  • Drop files and images on a pane to paste their paths.
  • App icon, agent logos and a foldable sidebar.
