Security and privacy

What leaves your PC

Agent Arcade has no cloud of its own, no telemetry and no account with us. It never asks for, reads or stores your AI logins. Here is every flow, and the limits we know about.

The ledger

Agent Arcade itselfNo telemetry, no analytics, no account with us. Internet traffic comes from the agents you run, from vendor installers when you click Install, and from the update check below.
Update checkFrom 1.3.4, once a day Agent Arcade asks GitHub's releases API (api.github.com) for the newest version number, and the sidebar shows a notice when there is a newer one. The request carries a generic User-Agent and no identifier: no version, no machine ID, no cookies. Like any web request it shows GitHub your IP address. It downloads nothing; you update yourself. Switch it off in the sidebar: click the version number.
Your AI loginsStay with the AI tools. Each agent signs in through its own official flow. To show which account is active, Agent Arcade asks the tool itself; for Gemini CLI it reads the signed-in email address Gemini keeps on your PC. It never switches, pools or rotates accounts.
Extra accountsA second Claude Code, Codex or Gemini CLI account gets its own folder (CLAUDE_CONFIG_DIR, CODEX_HOME, GEMINI_CLI_HOME). You sign in to each one yourself.
Chat historyOn your PC only: each chat's title, agent, account, folder and times. Never the conversation itself. A title you don't type yourself comes from the agent's terminal title or, until the agent names the chat, from the start of your first message (up to 120 characters), so it can describe the topic.
Phone remoteAgent screens and your typing go only between your phone and your PC, over your network or Tailscale. Off until you turn it on. Over Tailscale, when the two devices can't connect directly, Tailscale relays the encrypted traffic through its own DERP servers.
The window (Microsoft WebView2)From 1.3.3, SmartScreen reputation checks are off, so the addresses of pages shown in the window (the app's own page and Preview) aren't sent to Microsoft, and WebView2 crash dumps stay on your PC. Before 1.3.3, WebView2's defaults applied: SmartScreen checked page addresses with Microsoft, and crash reports went to Microsoft as far as your Windows diagnostic-data setting allowed.
Your agentsTalk to their own vendors under your accounts, exactly as they would in any terminal.
{{voice}} (coming with Pro)Not released yet. As planned, audio will stay in memory on your PC and prompt history will be a local file. Prompt Coach (planned) will send prompt text through your own Claude Code sign-in, only when you press Analyse.

The phone remote, in detail

  • Off by default. Agent Arcade listens on port 47821 only while Phone remote is on.
  • Local addresses only. It accepts private-network IPv4 addresses and the 100.64.0.0/10 range Tailscale uses. Every other address is dropped before the TLS handshake, even if a port is forwarded.
  • HTTPS only (TLS 1.2 or 1.3). The PC makes its own certificate once, kept in your Windows user certificate store with a key that can't be exported. The phone gets the certificate's fingerprint from the QR code and accepts no other certificate.
  • Pairing codes work once, for 10 minutes; five wrong codes cancel them.
  • Tokens. Each phone gets its own token. The PC keeps only its SHA-256 hash in remote.json, and Remove in the Phone dialog cuts that phone off at once.
  • A paired phone is as powerful as your keyboard in the panes. It can read, type, approve, start, stop, resume and rename agents in your listed workspaces. Agents run with your Windows permissions, so by typing to an agent a phone can reach your files indirectly, as you could at the PC. It can also make an empty project folder next to your projects (POST /projects: the phone sends only a name, which the PC checks). It has no way of its own to read files, change Agent Arcade's settings, start agents outside your workspaces or see account logins. Treat a paired phone like a key: keep it locked, and Remove a lost one at once.
  • Tailscale's relays. Away from home, Tailscale may relay the connection through its own DERP servers when the phone and PC can't reach each other directly. The traffic stays encrypted (Tailscale's own encryption and Agent Arcade's pinned TLS), but then it isn't a direct phone-to-PC link.
  • Logs. Tokens, pairing codes and terminal text are never written to the log.

Honest boundaries

  • Agents aren't sandboxed. They run with your normal Windows permissions and can change or delete files, as they would in any terminal. You're responsible for what you let them do.
  • Agents share the project folder. There's no per-agent git worktree isolation yet. The Changes tab shows every edit live.
  • Cloned projects can contain anything. From 1.3.3, agent sessions run with NoDefaultCurrentDirectoryInExePath=1, so a node.bat or node.cmd planted in a cloned repository no longer runs in place of Node.js when an agent's launcher starts node. An agent can still run whatever a project tells it to, so read what you clone.
  • Status detection is heuristic. It reads the agents' English terminal text, so treat it as a strong signal, not a guarantee.
  • No independent audit has been done. The source is public, so you can read it.
  • The download isn't code-signed yet. Check its SHA-256 on the download page. With Smart App Control on, Windows blocks unsigned apps and offers no per-app exception, so Agent Arcade can't run there until it is signed.

Check it yourself

The source is on GitHub. AgentArcade.exe --self-check runs the built-in checks, including the phone remote's TLS pinning, pairing limits and address filter, and writes the results to %TEMP%\AgentArcade-selfcheck.txt. That report also lists your agents' account emails and folder paths, so share only its FAIL lines. powercfg /requests shows the keep-awake request while agents run.

Report a vulnerability

Please report security problems privately through GitHub: open a private security advisory. Don't open a public issue for them. SECURITY.md has the details; security fixes go into the latest release.
