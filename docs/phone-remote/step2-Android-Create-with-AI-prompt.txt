Create "Agent Arcade Remote", an Android phone app in Kotlin with Jetpack Compose and Material 3 (phone, portrait and landscape, minSdk 26). It is the remote control for Agent Arcade, my Windows app that runs AI coding agents (Claude Code, Codex, Gemini CLI, GitHub Copilot CLI, Cursor) side by side, each in its own terminal pane, grouped by project folder ("workspaces"). With this app I check on my agents when I'm away from my PC: what each one is doing, how far along it is, and which ones need me. I can jump into an agent's chat to read its terminal, answer its question, approve or refuse what it asks, or give it a new instruction.

The attached images are the design. Match them closely: colors, spacing, corner radius, borders, status dots and text sizes. They copy the look of the desktop app, so the two feel like one product.

LOOK AND FEEL (dark only: no light theme, no dynamic color)
- Colors: background #0C0C0E; bars and bottom navigation #111114; cards #141418; raised fields and chips #1A1A1F; pressed #1F1F25; border #25252C; strong border #32323B; text #ECECF1; muted text #9A9AA6; faint text #63636F; accent #E07A5F (light accent #F0A080); green #3ECF7F; amber #F2B84B; red #F26B6B; terminal background #0F0F12; terminal text #E4E4E7; menus #19191E; sheets and dialogs #16161B; scrim black at 55%.
- Put these into a custom Material 3 darkColorScheme, so no default Material purple shows up anywhere.
- Flat: cards have a 1dp border and no elevation or shadow. Corners: cards 12dp, bottom sheets 20dp, dialogs 16dp, buttons 12dp (small buttons 9dp), chips 8dp, counters and tags fully round.
- Buttons: primary = #ECECF1 fill with #121214 text; secondary ("ghost") = card color with a 1dp strong border and text color; danger = #F26B6B fill with #1C0C0C text; text buttons in muted.
- Status dot: an 8dp circle on every agent. Green with a soft 3dp green halo (15%) = running. Amber that pulses (opacity 1 to 0.35 and back, 1.2 s) = needs you. Grey #4A4A54 = ended.
- Counter pill: 11sp, raised fill, strong border, muted text. The "live" variant is green text on 8% green with a 35% green border; the "need you" chip is the same in amber.
- Agent avatar: a rounded square (22dp with 7dp corners; 36dp with 10dp corners in the agent picker) filled with the agent's brand color darkened 18%, a bold white monogram in the middle (CC for claude, CX for codex, GM for gemini, CP for copilot, CU for cursor-agent; any other agent the first two letters of its name) and a thin inner border of white at 12%. Brand colors by command: claude #D97757, codex #10A37F, gemini #4F8CFF, copilot #A371F7, cursor-agent #7C8AA5. Any other agent gets hsl(hash % 360, 55%, 58%), where hash = hash * 31 + char code over its name.
- Type: default sans-serif. Screen titles 20sp semibold; card titles 15sp semibold; secondary lines 12-13sp muted; section headers 12sp semibold muted. Monospace for terminal text, activity lines, times, paths and versions. The welcome headlines use a serif font (FontFamily.Serif), regular weight, 30sp.
- Icons: thin rounded line icons (Lucide style, 1.8 stroke), not filled Material icons.
- Welcome and empty screens have a soft accent glow at the top (a radial gradient of #E07A5F at 10%).
- Edge to edge, with dark system bars.

SCREENS
1. Connect (first run): the logo, the serif headline "Connect to your PC", the line "Watch your agents, see how far they are, and help them when they ask.", a card with three numbered steps (1 Open Agent Arcade on your PC; 2 Click Phone at the bottom of the sidebar; 3 Turn on Phone remote and scan the code), the buttons "Scan QR code" (primary), "Paste pairing link" (ghost) and "Try the demo" (text button), and the tip "Your phone talks to your PC directly over Wi-Fi or Tailscale. Nothing goes through the cloud." For now the first two buttons show "Coming soon"; "Try the demo" opens the app with demo data.

2. Agents (home): an app bar with the logo, "Agent Arcade", a connection chip with the PC name (green dot = connected; pulsing amber "Reconnecting…"; grey "Offline" with Retry) and a small primary "New" button. Summary chips: "2 need you" (amber), "2 working" (green), "1 ended". Then a "Needs you" section, then one section per workspace (folder icon, or a cube icon for Unity projects; its name; a counter). Each agent is a card: status dot, avatar, chat title, time since its last output (mono, faint), a line like "Claude Code · second", and then one of these: the live activity line in monospace ("✻ Brewing… (1m 12s · esc to interrupt)"); a thin 4dp accent progress bar with "3/7 · current step" when the agent has a step plan; "Needs your OK · <its question>" in amber; "Done · your turn · <what it last said>"; or "Ended" with a "Resume" tag button. Cards in "Needs you" get an amber border at 32% and a faint amber glow at the top. Pull to refresh. Empty state: the serif headline "What are we building today?" and account cards to start an agent.

3. Chat (one agent): a top bar with back, dot, avatar, the title (tap to rename) and "Claude Code · second · HimalayanExpedition", and a ⋯ menu (Rename, Paste "save progress" prompt, Paste "continue" prompt, Ask for a status update, Alerts for this chat, and Stop agent in red with a confirm dialog). Under it a status strip: dot, the state in its color ("Working", "Needs your OK", "Done · your turn", "Idle", "Ended"), the time of the current turn (mono), and "Plan 3/7" with a mini progress bar that expands into the step list (done steps with a green check, the current one in the accent color, the rest faint). The middle is a read-only terminal: monospace 12sp, colored text runs on the terminal background, it sticks to the bottom as output arrives, shows a "Jump to latest" pill when scrolled up, pinch to zoom (9-24sp), long-press to select and copy. When the agent asks for approval, a card with an amber border sits above the input: "Claude Code needs your OK", the question, and one button per choice with a key badge ("1", "2", "3"; the first is primary, the others ghost). Under that: a scrollable row of key chips (Esc, Tab, ⇧Tab, ↑, ↓, ←, →, Enter, Ctrl+C, /, y, n) and the composer: a round quick-prompts button, the field "Message Claude Code…", a mic button and a round primary send button with an up arrow. Sending types the text into the agent and presses Enter. When the agent has ended: a pill "Session ended" with Resume, New chat and Close.

4. Start an agent (bottom sheet from "New"): pick a workspace (rows like the desktop sidebar; the chosen one is raised with a strong border and an accent icon), then an account card per agent account (big avatar, agent name, a plan tag like MAX, PRO or PLUS, a green running count, "main · you@example.com"). Agents that aren't installed are dimmed with "Not installed on your PC". Starting opens its chat.

5. History: a segmented filter (All projects, then each workspace) and chats grouped by project (name, path in mono, counter). Each row: avatar, title, "Today 14:02 · 23 min · main", and "Resume" (ghost), or "Open" with a status dot when it is still running.

6. Settings: Your PC (name, address, paired date, short fingerprint in mono, "Live" status, "Forget this PC" in red); Alerts (Stay connected in the background, An agent needs my OK, An agent is done, An agent stops); Terminal (text size slider 9-24, Wrap long lines); App (Demo mode, About).

Bottom navigation: Agents, History, Settings. The selected item has its icon in the accent color on a raised pill with a strong border.

DATA AND ARCHITECTURE
- Single activity, Navigation Compose with type-safe routes, one ViewModel per screen exposing StateFlow, Kotlin coroutines, kotlinx.serialization, DataStore for settings. No Hilt: a small AppContainer in the Application class.
- All data goes through an ArcadeRepository interface: flows for the PC state, the history, terminal screens and attention events, and suspend functions startAgent, resumeChat, stop, close, rename, sendText(text, submit), sendKeys, watchScreen and unwatchScreen.
